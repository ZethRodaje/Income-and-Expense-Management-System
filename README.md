# Income-and-Expense-Management-System

Small businesses often struggle with managing their income and expenses efficiently, relying on manual methods such as paper receipts or handwritten records that are prone to errors, loss, and inefficiency. This project addresses that gap by providing an affordable, secure, and automated solution designed specifically for small business owners who need to track their finances without expensive software.

The system allows users to register and log in securely, view a dashboard summary of their income, expenses, and profit, manage transactions through full CRUD operations, browse their transaction history, and filter records by date, category, or type. Optional features such as basic report generation and email notifications may be added as development progresses.

This authentication interface — consisting of a Sign In page, a Registration page, and an index overview — is the entry point of the portal, built with plain HTML, CSS, and JavaScript.
